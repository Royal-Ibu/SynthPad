# SynthPad
A custom MIDI keypad with 6 Kalih Choc switches, an EC11 Rotary Encoder, a Bourns slide potentiometer, capacitive touch keys, and a Waveshare ESP32-S3-ZERO! SynthPad was made as a submission for Hack Club's Half-Life Week 3 Challenge - Music Projects!

## Features

- Six Kailh Choc switches: Six low-profile mechanical keys for tactile input.
- EC11 rotary encoder: Provides rotary input and an integrated push-button input.
- Bourns slide potentiometer: Adds a sliding analog control for a MIDI parameter.
- Waveshare ESP32-S3-ZERO: Handles the controller's inputs and will run the MIDI firmware.
- Capacitive touch keys: Electronic touch pad switches for further inputs!
